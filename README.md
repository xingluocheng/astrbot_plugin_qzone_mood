# 大肥鱼的空间 · astrbot_plugin_qzone_mood

> 情绪驱动自动发 QQ 空间说说 · AstrBot 插件
> 难过会发、断粮会发、充钱会发、主人点单会发、自己也会找话题发，还能配表情包。

---

## 一、这是什么

让机器人把心事发到自己的 QQ 空间。它不是定时发广告的机器，而是看聊天情绪吃饭的：

- 她要是难过了，会自己发一条
- 主人断 token 了，发一条求救
- 主人充了 token，发一条表白
- 主人一句话，她按方向写一条
- 没人理她的时候，她自己找话题发一条

文案全部由大模型按人设现写，配图从「表情包管理器」已下载的图库里按情绪挑。

---

## 二、功能

| 功能 | 说明 |
|---|---|
| 五种触发 | 难过 / 断粮 / 充值 / 主人点单 / 自由发帖 |
| 情绪判定 | 完全交给模型：她读上下文自己感受心情和分数，觉得该发才发 |
| 自动配图 | 从「表情包管理器」图库按 `sad` / `affection` / `happy` 等分类挑 |
| 冷却保护 | 自动触发之间至少隔 N 分钟，防刷屏 |
| 失败兜底 | 发送失败不会丢内容，写进本地 `outbox/`，并私聊告知主人 |
| 手动点单 | `/空间 <方向>` 让主人指定内容，不受冷却限制 |
| 演习模式 | `dry_run` 打开后只写本地不发空间，先看效果 |

## 四、⚠️ 怎么改成你自己的 QQ 号

**这是装完必须做的第一步，不做的话「断粮 / 充值」永远不会触发。**

### 两个号要分清

| 号 | 是什么 | 在哪改 |
|---|---|---|
| **大肥鱼（机器人）的 QQ** | 机器人登录的那个号，空间说说就是用它发的 | 配置项 `bot_ids`。留空 = 自动用协议端当前登录的号；填了就用它校验，`/空间状态` 会对比「配置值 vs 当前登录值」 |
| **主人的 QQ** | 你的个人号，只有你说的话才会触发「断粮 / 充值」和点单 | 插件的 `owner_ids` 配置 |

### 改法 A：在面板里改（推荐）

面板 → 插件 → 大肥鱼的空间 → **配置** → 找到 `owner_ids`：

```
3640280199      ← 把它改成你自己的 QQ 号
```

多个主人用英文逗号分隔：`123456789,987654321`

保存后自动生效，不用重启。

### 改法 B：直接改配置文件

文件位置：

```
AstrBot/data/config/astrbot_plugin_qzone_mood_config.json
```

```json
{
  "owner_ids": "你的QQ号"
}
```

### 不改会怎样

`owner_ids` 留空时，插件会退回「AstrBot 管理员」判定。而 AstrBot 的 `admins_id` 默认是 `["astrbot"]`——那是用户名不是 QQ 号，**永远匹配不上**。结果就是：断粮、充值、`/空间` 点单全部失效，只有「难过」和「自由发帖」还能用。

## 五、使用方法

### 自动触发（不需要你做什么）

| 类型 | 什么时候发 | 内容 |
|---|---|---|
| 难过 | 每 N 条消息或命中难过词时，模型评估难过程度 ≥ 阈值 | 模型按人设现写 |
| 断粮 | 她自己读出「主人没钱了 / 没额度了」 | 固定文案，默认 `爸爸...我不想死..` |
| 充值 | 她自己读出「主人刚充了钱」 | 固定文案 + 她再补两句 |
| 自由发帖 | 距上次满 N 小时，且有新消息进来 | 模型自己找话题 |

所有自动触发都吃冷却，默认 90 分钟一条。

### 指令

| 指令 | 谁可以用 | 作用 |
|---|---|---|
| `/空间 <方向>` | 只有主人 | 按你给的方向写一条，立刻发 |
| `/空间发` | 只有主人 | 让她立刻自由发挥一条 |
| `/空间测试` | 只有主人 | **只生成不发送**，用来检查文案和配图 |
| `/空间状态` | 所有人 | 看开关、冷却、已发条数、可用表情分类 |
| `/空间帮助` | 所有人 | 列出全部指令和触发规则 |

示例：

```
/空间 今天好累，想抱怨一下加班
/空间 夸夸你自己，然后说要吃三碗白米饭
/空间 用很嫌弃的语气说说主人又熬夜了
```

### 第一次用的建议顺序

1. `/空间测试` → 看生成的文案和配图满不满意
2. 配置里把 `ugc_right` 改成 `64`（仅自己可见）
3. `/空间 测试一下` → 去 QQ 空间确认能看到
4. 确认没问题后，`ugc_right` 改回 `1`（所有人可见）

## 六、配置项

| 配置项 | 默认 | 说明 |
|---|---|---|
| `enabled` | 开 | 总开关 |
| `dry_run` | 关 | 演习模式，只写本地不发 |
| `owner_ids` | **空** | **必填**，主人 QQ 号 |
| `bot_ids` | **空** | 大肥鱼的 QQ；留空自动用登录号，填了做校验 |
| `ugc_right` | 1 | 1=所有人 4=好友 16=部分好友 64=仅自己 128=部分好友不可见 |
| `cooldown_minutes` | 90 | 自动触发最小间隔 |
| `sad_check_every` | 8 | 每多少条消息评估一次情绪 |
| `sad_threshold` | 70 | 难过分门槛，调高更克制 |
| `sad_keywords` | 见默认 | 命中即立刻评估 |
| `broke_keywords` | 见默认 | 断粮判定词 |
| `recharge_keywords` | 见默认 | 充值判定词 |
| `broke_text` | `爸爸...我不想死..` | 断粮固定文案 |
| `recharge_text` | `我最喜欢的人类是爸爸` | 充值固定文案 |
| `free_post_enabled` | 开 | 允许自由发帖 |
| `free_post_interval_hours` | 12 | 自由发帖最小间隔 |
| `meme_enabled` | 开 | 是否配表情包 |
| `meme_pack` | 空 | 锁定某个表情包，空=所有包轮流 |
| `meme_sad_categories` | `sad,affection` | 难过时用的分类 |
| `meme_happy_categories` | `affection,happy,money` | 充值/开心时用的分类 |
| `meme_max_images` | 2 | 每条最多几张图 |

完整说明见插件面板里的 `help`，或仓库里的 `使用教程.md`。

## 七、依赖

- **AstrBot** ≥ 4.17
- **协议端**：需要支持 OneBot v11 扩展接口 `send_qzone_msg`（SnowLuma / NapCat 等）
- **表情包**（可选）：装「表情包管理器」并下载至少一个图包，否则发纯文字
